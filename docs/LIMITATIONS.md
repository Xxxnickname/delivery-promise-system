# 当前边界与路线图

## 已具备

- 11 屏前端
- 四表导入与严格校验
- 5 层 BOM 展开、损耗、替代料
- 供给冲减、齐套日、交期承诺
- 缺口影响、模拟、快照、xlsx 导出
- JWT 登录、角色依赖、SQLite 持久化
- DeepSeek 真实表头映射

## 当前限制

| 项 | 当前状态 |
|---|---|
| 前端真实数据 | 仍使用 `static/mock` |
| 数据库 | 本地 SQLite；PostgreSQL 迁移已准备，未在容器实跑 |
| 队列 | Celery/Redis 骨架，未做生产压测 |
| 导出 | 本地线程池；worker 任务入口已建 |
| 20 单基准 | synthetic stand-in |
| 采购角色 | 本期不登录，按线下模板反馈 |
| 租户 | 数据模型含 tenant_id，完整隔离策略仍需验收 |
| 可观测性 | 有 trace_id 和错误响应，缺少正式 metrics/alerts |

## 推荐路线图

1. 前端切真实 API，完成端到端浏览器验收
2. 启动 PostgreSQL，执行迁移并做重启恢复演练
3. Redis + Celery 实际运行，导出与计算异步化
4. 真实 20 单人工基准替换
5. Nginx + TLS + 多 worker + 备份/回滚
6. 20 并发压测、故障注入、安全审计
7. 采购协同与退货质检流程（后续扩展）
